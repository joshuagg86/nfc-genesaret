# Cafetería Gene — Android de capacitación

Capacitor 8 con recursos web locales. La primera compilación utiliza exclusivamente Firebase de capacitación y un identificador de paquete separado de la APK TWA. No sustituye la app instalada. No usar server.url en producción. NFC nativo, cámara, icono, firma de distribución y estrategia de actualizaciones requieren validación posterior.

Desde este directorio: npm install; npm run android:add (solo primera vez); npm run android:sync (actualizaciones); npx cap open android. Android Studio 2025.2.1 o posterior y SDK 36.
